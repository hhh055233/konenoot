# כוננות — Konenoot

אפליקציית Expo בעברית ובתצוגת RTL למרכז עדכונים קהילתי, דיווחי בטיחות כלליים וכלי ניהול בהדגמה.

## מה כלול כרגע
- מסך בית ומרכז עדכונים.
- פרסום עדכון בתצוגה המקומית.
- טופס דיווח כללי על מפגעי בטיחות.
- מסך ניהול עם בקשות הצטרפות לדוגמה.
- ממשק עברי, RTL ועיצוב מותאם למכשירים ניידים.

## הפעלה
1. התקינו Node.js ו־npm במחשב.
2. הריצו `npm install`.
3. הריצו `npx expo start`.
4. פתחו באמצעות Expo Go או אמולטור Android.

## מצב הפרויקט — אבטיפוס
הנתונים נשמרים בזיכרון של האפליקציה בלבד. אין עדיין שרת, חשבונות משתמשים אמיתיים, הרשאות מאובטחות, סנכרון בין מכשירים או התראות Push. פעולות האישור והפרסום הן הדגמה מקומית בלבד.

## דרישות לפני שימוש אמיתי
יש לחבר backend מאובטח, אימות משתמשים, הרשאות שנאכפות בצד השרת, אחסון נתונים, ניטור, גיבויים ובדיקות אבטחה. אין להסתמך על אבטיפוס זה לצורך הזעקה או תיאום פעילות מבצעית.

## פרטיות ובטיחות
האפליקציה מיועדת לעדכונים כלליים ולדיווחי בטיחות קהילתיים. אין להוסיף או לשמור מיקומים מדויקים של אנשים או צוותים, מסלולי תנועה, נקודות פריסה, מידע על אמצעי לחימה או מידע מבצעי רגיש.
